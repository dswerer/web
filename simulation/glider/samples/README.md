# 样例轨迹文件

`flight_trace_sample.bin` —— 一次真实仿真产出的 **ftrc 二进制**轨迹。

- 参数：上反角 5°、重心 0、36 m/s、150 m 投放（默认机型 17.5 m² / 420 kg）；
- 结果：`landed`，72.73 s，水平距离 2287 m，升阻比 ≈ 15.4；
- 数据：**8729 帧 × 13 列**（11 状态 + CL/CD），120 Hz 均匀采样，453 928 字节。

**用途**：**不启动服务、不依赖数据库**，直接解析该文件即可联调渲染——
解析代码见 [`../RENDER_API.md`](../RENDER_API.md) 第 3、5 节。
生产链路中该文件由物理仿真产出、被后端存入数据库、经 `/trace` 接口下发，格式完全一致。

> 自检：魔数应为 `"FTRC"`；文件长度应等于 `20 + 帧数 × (11 + extra_dim) × 4`。
